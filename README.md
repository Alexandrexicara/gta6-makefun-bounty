# GTA 6 Meme — make.fun bounty

A static preview project for the **“Post a GTA 6 meme on X”** make.fun bounty.

## Preview
Open `index.html` locally or deploy this repository to Netlify. The page contains an original, editable-in-source meme composition and a button to export a PNG draft.

## Deploy on Netlify
Connect this public GitHub repository to Netlify and use the repository root as the publish directory. No build command is required.
